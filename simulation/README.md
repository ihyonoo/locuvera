# simulation

Locuvera의 상시 가동 가상 병원 시뮬레이터. 실물 RTLS 하드웨어 없이도
시연 가능한 규모의 트래픽을 만들어 백엔드에 HTTP로 보낸다.

## 무엇을 시뮬레이션하는가

순천향대학교 천안병원 본관 1~5층 구성을 본뜬 가상 병원 하나.

- 구역(리더) 42개 — 실물 리더가 담당하는 M501(중앙수술센터)·M502(통원수술센터)는 제외
- 장비(태그) 50대, 20종(수액펌프·제세동기·초음파진단기 등 이동형 의료기기)
- 의료진 120명 — 직종·담당 층·3교대(주간/저녁/야간) 또는 평일 상근/온콜로 나뉜다

전부 `is_real_hardware = FALSE`로 표시되어 실물 태그·리더·계정과 섞이지 않는다.

## 실행

```bash
python -m simulation.apply_seed   # DB에 시드 적용 (최초 1회, 또는 topology 변경 후)
python -m simulation.simulator    # 상시 가동 시작
```

둘 다 저장소 루트에서 실행하고 `simulation/.env`(`.env.example` 참고)가 필요하다.
`bash scripts/dev-up.sh`는 스키마 적용 → `apply_seed` → 백엔드/프론트엔드 기동 →
시뮬레이터 기동까지 한 번에 처리한다.

## 환경 변수 (`simulation/.env`)

| 변수 | 용도 |
|---|---|
| `BACKEND_BASE_URL` | 시뮬레이터가 요청을 보낼 백엔드 주소 |
| `DATABASE_URL` | `apply_seed` 전용. 시뮬레이터 런타임은 DB에 접근하지 않는다 |
| `REDIS_URL` | `apply_seed`가 재시드 시 태그 위치 캐시(`rtls:tag:*`)를 정리하는 데 쓴다 |
| `SIM_STAFF_PASSWORD` | 시뮬레이션 staff 120계정 공통 비밀번호. 없으면 시뮬레이터가 즉시 종료된다 |
| `RTLS_SIM_KEY` | `/ingest` 요청 서명 키. 백엔드 루트 `.env`의 값과 동일해야 한다 |
| `SIM_RANDOM_SEED` | 비우면 매 기동이 다른 궤적을 그린다. 값을 주면 재현 가능해진다(디버깅용) |

## 모델 요약

- **전파**: `RSSI(d) = -59 - 20·log10(d) - 6·(벽 홉 수) + 개체차 + 느린 노이즈(OU) + 빠른 노이즈`.
  수신 감도 −95dBm, 최대 유효 거리 40m. 벽 홉 수는 태그 구역과 리더 구역 사이 인접
  그래프 최단 홉으로 근사한다.
- **이동**: 장비는 인접 그래프(42노드 51엣지, 구역 폴리곤 경계 간격에서 도출)의
  최단경로를 따라, 사람이 밀고 걷는 속도(평균 1.1m/s)로만 이동한다. 층을 넘지 않는다.
- **수요 곡선**: 장비를 급성기(24시간 가동, 주말 영향 적음)와 외래(진료 시간에 집중,
  야간·일요일에는 거의 멈춤) 두 클래스로 나눠 시간대·요일 배율을 곱한다. 동시 대여
  수가 목표 밴드(주간 8~14대, 야간 2~4대)를 벗어나면 피드백 계수가 체크아웃 확률을
  밀거나 당긴다. 야간에는 드물게 응급 버스트(3배 배율)가 발생한다.
- **상태 머신**: `AVAILABLE → TRANSIT → IN_USE → (TRANSIT → IN_USE)* → RETURNING → 반납`.
  대여 1건은 사용지 1~4곳을 거치며(1곳이 절반 이상), 시각·구역·직종 조건을 모두
  만족하는 근무 중 직원만 대여·반납할 수 있다.
- **예외 이벤트**: 예상보다 오래 사용(5%), home 복귀율을 무시한 엉뚱한 위치 반납(3%),
  스캔 실수 후 즉시 반납하는 미스탭(2%), 대여자가 퇴근한 뒤 동료가 대신 반납하는
  대리 반납(퇴근 시 85%, 근무 중에도 4%).

## 예상 규모

평일 주간 동시 대여는 평균 8~9대, 야간은 3대 안팎이다(피드백 제어가 목표 밴드로
당기지만 확률적으로 잠깐 벗어나기도 한다). 하루 대여는 약 142건(24시간 오프라인
측정 기준).
